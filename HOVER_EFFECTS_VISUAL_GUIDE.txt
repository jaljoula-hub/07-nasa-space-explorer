    LAYER 1: Immediate Feedback (0-100ms)

    └─ Cursor changes to pointer

    LAYER 2: Primary Animation (100-300ms)

    └─ Image begins scaling
    └─ Badge begins bouncing

    LAYER 3: Secondary Effects (300-500ms)
    └─ Shadows enhance
    └─ Scale completes
    └─ Colors fully transition

                     ♿ ACCESSIBILITY

For users with motion sensitivity:
  • Animations are instantly disabled
  • All colors still change (visual feedback maintained)
  • Full functionality preserved
  • No delays or confusion

Enable in DevTools:
  1. F12 → Settings
  2. Rendering → Emulate CSS media feature prefers-reduced-motion
  3. Reload → All animations become instant
